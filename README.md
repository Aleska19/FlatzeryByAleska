# Flatzery By Aleska

Proyecto de desarrollo web para Flatzery, una empresa dedicada al diseño de interiores.

## Estructura del Proyecto

- `/assets` - Recursos multimedia e imágenes
- `/css` - Archivos CSS compilados
- `/html` - Páginas HTML del sitio
- `/js` - Scripts de JavaScript
- `/scss` - Archivos fuente de SASS

## Tecnologías Utilizadas

- HTML5
- CSS3/SASS
- JavaScript
- Bootstrap (si aplica)

## Instalación

1. Clonar el repositorio
```bash
git clone https://github.com/Aleska19/FlatzeryByAleska.git
```

2. Instalar dependencias (si las hay)
```bash
npm install
```

## Desarrollo

Para compilar SCSS a CSS:

```bash
npm run sass
```
